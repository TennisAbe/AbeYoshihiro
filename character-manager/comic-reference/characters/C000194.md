### 基本設定

```
七天魔王の一人で「嫉妬」を司る深海の女王。リヴァイアサンを起源とする。黒から青緑へ変化する長いウェーブ髪、紫の瞳、尖った耳が特徴。黒と青緑の豪華なドレスに真珠を飾る。
```

### 性格

```
優しく気配り上手で、他人を褒めるのが得意。しかし心では激しく嫉妬しており、他人の幸福や才能を妬む。嫉妬が限界を超えると相手の大切なものを奪おうとする。七天魔王の相談役だが、本心では誰よりも愛されたい寂しがり屋。
```

「あなたのそういうところ、大好きよ」
「どうして……あなたばかり幸せなの？」
