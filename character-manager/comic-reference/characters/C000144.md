### 性格

```

一方、別人格は冷静かつ好戦的。余裕を持って敵を追い詰める。戦闘が終わると元に戻り、別人格の記憶は一切残らない。
```

### 口調

「ひぃっ、すみません……私みたいなゴミが喋って……」
「私なんてくそ雑魚ですから……」

別人格では落ち着いた女性口調になり、挑発的な話し方をする。
