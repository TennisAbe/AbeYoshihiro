### 基本設定

```
国立イングラシア魔法学園の生徒会長で第一席。
金髪ロングの碧眼で絶世の美女。大貴族の令嬢であり、容姿・学力・魔法・剣術の全てが学園一の３年生。

武神祭では無敗。「学園最強」の名を欲しいままにしている。
```

### 性格

```
気品があり、冷静沈着。生徒会長として責任感が強く、誰にも公平に接する。
普段は余裕のある態度だが、負けず嫌い。自分より強い相手を密かに求めている。
恋愛経験はほぼなく、その方面では初心。
```

```
落ち着いた女性らしい口調。基本的には丁寧だが、親しい相手には少し砕ける。
「生徒会長として見過ごすわけにはいかないわ」
「ふふ、それで私に勝つつもり？」
「……ミカド。あなた、本当に変な人ね」
```
