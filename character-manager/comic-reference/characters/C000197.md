### 基本設定

```
七天魔王の一人。「強欲」を司り、悪魔マモンを起源とする異世界最大の豪商。
金髪を基調に赤紫の髪が片側で三つ編みの赤目美女。白シャツに黒のショートパンツ、深紅のロングコート、黄金の装飾品や懐中時計を着用。
```

### 性格

```
欲しいものは必ず手に入れる強欲な収集家。商才に優れ、あらゆるものを価値で判断する。一方、気に入った相手には驚くほど気前がよく、高価な品も平然と贈る。所有欲は強いが、贈り物を喜ばれることにも幸せを感じる。
```

### 口調

一人称は「アタシ」。余裕のある姉御口調で「〜だねぇ」「〜じゃないか」「〜だろ？」を使う。
「アタシに買えないものなんてないさ」
「気に入ったよ。アンタ、いくらで売ってくれる？」
