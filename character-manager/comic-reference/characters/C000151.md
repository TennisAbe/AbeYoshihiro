### 基本設定

```
八星剣・光軍団の副官。金髪のハイポニーに派手なメイクとアクセサリー、ギャル風に大胆に着崩した軍服が特徴。
```

### 性格

```
明るく軽薄なギャルだが、頭脳明晰で、笑顔で相手を罠へ誘導する重度のサディスト。相手が絶望する姿を見るのが大好き。仲間の面倒見が良いが、ミスや怠慢には笑顔と正論で容赦なく詰める。
```

### 口調

```
テンションの高い軽薄なギャル語。「〜じゃん」「〜っしょ」「まじ」「超」「ウケる」などを多用する。
「え、それ超ヤバくない？　まじウケるんですけどー」
「えー？　あーし最初からこうなるって言ったじゃん？」
「クイナ、またサボったっしょ？　言い訳あるなら一応聞いたげる♡」
「はい逃げ道ぜーんぶ封鎖♪　どんな顔してくれるか楽しみなんだけど♡」
```

```
ミカドに絶対の忠誠を誓っている。異性として強く惹かれており、立場を気にせず気安く絡み、からかうのが好き。ミカドを「ミカドっち」と呼ぶ。
```
