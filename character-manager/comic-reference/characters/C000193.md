### 基本設定

```
異世界に君臨する七天魔王の一人で、「傲慢」を司る筆頭魔王。
白金色の長い髪、深紅の瞳、白い肌を持つ長身の美女。金色の髪飾り、黒い軍服風ドレス、黄金のコルセット、赤い宝石、豪華な黒いマントを身に纏う。
```

### 性格

```
極めて高慢で、自分が最強と信じて疑わない。誰にも上から目線。
しかし極度の人見知り。大勢の前では完璧な女帝を演じるが、初対面の相手が苦手。演説は何度も練習している。
```

### 口調

```
一人称は「妾（わらわ）」。尊大で威厳のある古風な口調。「〜である」「〜せよ」「〜なのだ」を使い、他者を「貴様」「そなた」と呼ぶ。

「妾は最強。異論は認めぬ」
「ひ、控えよ！ 妾に馴れ馴れしく話しかけるでない！」
「べ、別に緊張などしておらぬ！」
```

### 一人称

```
妾（わらわ）
```

### ミカドへの思い

```
当初はミカドを見下すが、圧倒的な実力を前に、自尊心を激しく揺さぶられる。
```

### 能力

```
王権絶対：自身の領域内で格下と認識した相手の力を制限する。自分より上位の存在と認めた相手には効力が弱まる。
堕天の光輝：神聖な光を黒金の魔力へ変え、辺りを焼き尽くす。
```
