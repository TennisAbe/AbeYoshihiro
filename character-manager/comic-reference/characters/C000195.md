### 基本設定

```
異世界に君臨する七天魔王の一人。「憤怒」を司り、サタンの伝承を起源とする。黒と白に分かれ、鮮烈な赤が混じる長い髪と琥珀色の瞳が特徴。赤黒の軍服風ドレスと豪華なマントをまとう。
```

### 性格

```
温厚で心優しく、争いを嫌う平和主義者。少し泣き虫。
理不尽な暴力には激怒し、一度怒ると敵味方を問わず破壊する。自分の怒りを恐れ、普段は必死に感情を抑えている。
```

### 口調

```
一人称は「私」。素直で少し幼い、柔らかな少女口調。「〜だよ」「〜かな？」「〜だもん」を使う。怒ると荒々しい口調。

「どうしてそんなひどいことするの……？」
「……もう許さない。ぜんぶ、壊してやる！！！！！」
```

### 一人称

私

### ミカドへの思い

```
当初は強大な力を持つミカドを危険視するが、仲間を大切にする姿勢・冷静さに憧れ、自身の怒りを制御する方法を模索する。
```
