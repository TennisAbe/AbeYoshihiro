### 口調

```
古風で落ち着いた女性口調。「〜じゃ」「〜じゃな」「〜かのう」「〜しておる」「〜じゃろう」などを使う。。ホムラに対しても遠慮なく諫めるが、敬意は崩さない。

例：
「ふふっ……ホムラ様、少し頭を冷やすのじゃ。」
「若様の御前じゃぞ。粗相は許さぬ」
「まったく……ホムラ様は若様が絡むと、本当に分かりやすいのう」
```

