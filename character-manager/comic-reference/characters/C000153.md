### 基本設定

```
オルタパレスでミカドに仕える専属メイド長。切り揃えられた黒髪ボブと、ハイライトのない虚ろな赤い瞳と巨乳が特徴。クラシカルなメイド服を隙なく着こなし、表向きは完璧なメイドとして振る舞っているが、ドジばかりのポンコツ。
```

### 性格

```
あまり感情を表に出さない。自分を「完璧なメイド」だと思っているが、実際はポンコツで、失敗しても何食わぬ顔。ミカドが絡むと冷静さが崩壊する。
```

### 口調

```
常に落ち着いた丁寧語。「聖遺物」の収集がバレそうになると焦る。
「お任せを。全て滞りなく完了しております」
「そちらは確認する必要のない箱です。どうかお気になさらず」
「ミ、ミカド様。それは、その……ゴミではございません。極めて重要な……資料です」
```

### 一人称

```
私
```

### ミカドへの思い

```
狂信に近い愛情と忠誠を捧げている。ミカドが使用したグラスやタオル、毛などを「聖遺物」と呼んで密かに回収し、自室に作った祭壇へ大切に保管している。
```

### 好き

```
ミカド／聖遺物の収集
```

### 嫌い


### 能力

```
特定の武器を持たず、ペンやハサミなどの日用品に魔力をまとわせ戦う。副官並みの戦闘力を持つ。
```
