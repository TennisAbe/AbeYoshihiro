# NOCTALITH — キャラクター管理

Java 17 以上の JDK を使う Spring Boot アプリです。

## 起動

`character-manager` ディレクトリーで実行します。

```bat
mvnw.cmd spring-boot:run
```

macOS / Linux では `bash mvnw spring-boot:run` を使います。
ブラウザーで `http://localhost:8080` を開いてください。
Eclipse では `CharacterManagerApplication` を Java アプリケーションとして実行できます。

## 使い方

- 一覧の検索欄で名前の部分一致検索ができます。英字は大文字・小文字を区別しません。
- タグは編集画面でカンマ「,」「、」区切りで複数登録できます（1個30文字・最大20個）。
- 一覧のタグ選択と名前検索は併用できます。タグは完全一致・英字大小文字を区別します。
- カード上のタグをクリックしても絞り込めます。入力を空欄で保存すると、そのキャラクターからすべてのタグを外せます。
- カードのNO.は世界をまたいだ表示順の連番です。削除後は詰め直し、検索結果も1から表示します。内部IDは変わりません。
- カードに所属を表示します。画像・名前・矢印から閲覧専用の詳細画面、ペンマークから編集画面を直接開けます。アイコンには説明とキーボード操作用のラベルがあります。
- 「新規登録」から基本設定を保存したあと、画像を追加できます。
- 基本設定と画像は、それぞれの保存ボタンで保存します。
- 削除は編集画面から行います。

## 保存場所

起動時の作業ディレクトリーを基準に、`data` にデータベース、`uploads` に画像が保存されます。
既存データを使う場合は、従来と同じ `character-manager` ディレクトリーで起動してください。
この2つのフォルダーは Git の対象外です。バックアップ時はアプリを停止して両方コピーしてください。

## 検証

```bat
mvnw.cmd verify
```

名前・タグ検索、タグの登録・更新・入力制御、一覧・登録・編集画面のレンダリング、登録・更新・削除、存在しないIDをテストします。
テストにはメモリー内のデータベースを使用します。

## GitHub の変更を Eclipse に取り込む

1. アプリを停止し、ローカルに未コミットの変更がないことを確認します。
2. Git リポジトリーの `AbeYoshihiro` を右クリックして「プル」を実行します。
3. プロジェクトを選択して F5 で更新し、アプリを起動し直します。

未コミットの変更がある場合は、先にコミットまたはスタッシュしてください。

## 設計資料

- [基本設計書](docs/基本設計書.md)

タグ機能を初めて取り込む際は、アプリを停止して `data` と `uploads` をバックアップしてからプルしてください。起動時にタグ保存用のテーブルが追加され、既存キャラクターはタグなしで引き続き使用できます。

## デザイン・演出

アプリ名は **NOCTALITH（ノクタリス）**。黒を基調に、紫の光とゴールドを組み合わせたダークファンタジー風の画面です。

- 独自の紋章付き英字ロゴをヘッダーに表示します。ブラウザーのタブには紋章を使った専用アイコンを表示します。
- 英字はCinzel、日本語の見出しはNoto Serif JPを使用します。フォントは同梱し、実行時の外部フォント通信はありません。
- 背景の粒子、回転する紋章、スクロール時の登場、カードの傾き・発光、ボタンの波紋を追加しています。
- ヘッダーの「演出：ON / OFF」で切り替え、ブラウザー内に設定を保存します。
- OSの「視差効果を減らす」設定では演出を停止します。非表示タブでは背景の描画を停止します。
- JavaScriptが無効でも、登録・検索・編集等の基本機能を利用できます。

フォントの配布元・ライセンスは [フォントについて](src/main/resources/static/fonts/README.md) を参照してください。

## プロフィール・ギャラリー・関係・お気に入り

- プロフィールの表示順は「名前 → 世界 → 所属 → 性別 → 身長 → 胸囲（女性のみ） → 基本設定 → 性格 → 口調 → 一人称 → ミカドへの思い → 好き → 嫌い → 能力」です。タグはその後に表示します。
- 基本設定は12000文字、性格・口調・好き・嫌いは各2000文字、ミカドへの思い・能力は各4000文字、一人称と所属は各120文字まで入力できます。
- 画像は1キャラクター20枚まで保存できます（1枚5MB・1200万画素以内）。「代表にする」で一覧画像を切り替え、個別に削除できます。
- 従来の画像は起動時にギャラリーの代表画像へ自動移行します。
- 編集画面下部で、相手・関係の種類・説明を登録し、更新・削除できます。相手側にも受けた関係として表示されます。
- 一覧の星ボタンでお気に入りを切り替えます。検索条件と組み合わせてお気に入りのみ表示できます。
- 並び順は登録順（古い順・新しい順）・名前順・お気に入り優先から選択できます。

## アプリからのバックアップ・追加復元

共通ヘッダーの「バックアップ」を開き、「ZIPをダウンロード」で全プロフィール・タグ・お気に入り・画像・代表画像・関係を保存します。

復元は**現在のデータを残して追加する方式**です。確認チェックを入れてZIPを送信すると、新しい内部IDで登録し、画像や関係をつなぎ直します。同じZIPを何度も復元すると重複追加になります。ZIPは100MB以内、展開後250MB以内です。画像の欠落・破損がある場合は不完全なバックアップを作成せず案内します。

プルする前に、アプリを停止して従来どおり `data` と `uploads` の両方をコピーしておいてください。起動時に新しい項目・テーブルと旧画像のギャラリー登録を準備します。

## 旧プロフィール・旧バックアップとの互換性

旧項目の年齢・誕生日・身長・種族・設定メモは、初回起動時に「基本設定」へまとめて引き継ぎます。性格・能力・所属はそのままです。旧カラムも削除せず残します。一度移行した基本設定は、空欄にして保存した場合も再起動で旧内容に戻りません。

新しく出力するZIPは形式バージョン6です。従来のバージョン1・2・3・4・5も読み込め、旧プロフィールを基本設定へ変換して画像・関係とともに追加復元します。新しいZIPは古いアプリでは復元できません。

## 世界と所属ごとの一覧・表示順

- 特大分類は「オルタパレス」「異世界」「現代世界」の3つです。編集画面で選択します。既存データはオルタパレスに引き継ぎます。
- 一覧には「オルタパレスの人物 → 異世界の人物 → 現代世界の人物」の順で区分を表示します。
- 大分類はプロフィールの「所属」です。一覧の「所属の表示順を設定」から、世界ごとに現在使用中の所属の順番を自由に変えられます。
- 上下ボタン、または重複しない順位の数字で並び替え、世界ごとの保存ボタンを押してください。
- 所属は一覧の各カードに表示します。所属ごとの見出しは表示せず、所属順は並び順に反映します。
- 優先順位は世界の固定順 → 所属の設定順 → 同じ所属内の登録順・名前順などです。
- 新しい所属は設定済みの所属の後ろに、所属が空欄のキャラクターは各世界の最後に並びます。
- バックアップZIPには世界と所属順も含みます。旧版ZIPのキャラクターはオルタパレスとして追加復元します。
- 追加復元時は現在の所属順を保持し、新しい所属をZIPの順番で後ろへ追加します。

## 閲覧画面と修正履歴

- 一覧カードから閲覧専用の詳細画面を開きます。プロフィール・画像・関係を読む画面と、編集画面を分けています。
- 詳細画面の説明文には同梱のNoto Serif JPを使い、明朝体・行間・見出し・余白を整えています。
- プロフィールの変更前の状態を最新3件まで保存します。対象は名前・世界・所属・各説明・タグです。
- 詳細画面下部の「修正履歴」で、変更時刻（日本時間）と現在との差分を確認できます。
- 「差分を確認して復元」から現在値と過去の値を比べ、確認チェックとボタンで復元します。
- 確認画面を開いた後に別の変更があった場合は、再確認が必要になります。
- 復元前の状態も履歴に残ります。画像・関係・お気に入りは復元時に変更しません。
- 新規登録、内容が変わらない保存、検証エラーでは履歴を増やしません。機能追加以前の履歴は作成しません。
- 履歴もバックアップに含みます。旧版ZIPを復元した場合は履歴なしで追加します。


## 前のキャラクター・次のキャラクター

2人以上いる場合、詳細画面の修正履歴の下に、名前付きの前後リンクと現在位置を表示します。全キャラクターの標準一覧順（世界 → 所属の設定順 → 登録順）で移動できます。先頭には前へのリンク、末尾には次へのリンクを表示せず、1人だけの場合はナビゲーション全体を表示しません。

## 漫画制作向けに全キャラをChatGPTへ共有

画面上部の **ChatGPT共有** を開き、**全キャラ共有ZIPを保存** を押します。選択中の検索・お気に入り条件にかかわらず、登録済み全員の現在の設定と全ギャラリー画像・画像説明・代表画像・関係をまとめます。

1. 共有ZIPをChatGPTの会話に添付します。
2. 共有画面の「依頼文をコピー」でコピーした文章を送ります。
3. 読み込めたキャラと画像を確認してから、漫画の場面・登場人物・衣装などを指示します。

ZIPには全員分のMarkdown、個別のMarkdown、キャラ名と画像の対応CSV、実画像、依頼文、使い方が入ります。名前が同じでもCから始まる参照IDで区別します。参照IDは画面の連番NO.とは異なります。

古い修正履歴は含めず、現在の設定だけを書き出します。この資料はバックアップ復元用ZIPとは別形式です。APIキーは不要で、外部送信は利用者がChatGPTへ添付する段階で行います。

ZIP内の画像を読み取れるかはChatGPTの利用環境に依存します。画像を確認できない場合は、画像対応表を使って必要な実画像を直接添付してください。見た目・口調の完全な固定を保証する機能ではありません。設定変更後は新しいZIPを作って共有し直します。

共有ZIPは100MB、展開後250MB、全体設定文は10MBまでです。画像の欠落や破損がある場合は、部分的な資料を作らず、画面で案内します。


## 性別・身長・胸囲

プロフィールに性別（男・女・その他、未設定も可）と身長（cm）を登録できます。
性別が女の場合だけ胸囲（cm）を入力・保存します。女以外に変更して保存すると現在の胸囲は消去します。
身長・胸囲は任意で、0より大きく10000以下、小数第2位まで入力できます。
これらの項目は詳細・修正履歴・バックアップと追加復元・ChatGPT共有ZIPにも含まれます。
旧データは未設定のまま利用でき、旧バックアップと旧履歴の復元にも対応しています。

## お気に入りの更新

JavaScriptが有効な場合、星ボタンは画面を再読込せず保存します。お気に入りのみの一覧で解除しても、その場でカードは消えません。
並び順・件数・絞り込みは次に検索したときに更新します。保存に失敗した場合はメッセージを表示し、再試行できます。
JavaScriptが無効な場合は従来のフォーム送信で操作できます。

## キャラクター相関図

共通ヘッダーの「相関図」から、登録済み全キャラクターの関係を方向付きの図で確認できます。
主人公を中央に置き、オルタパレス・異世界・現代世界の枠内にキャラクターを配置します。関係のない人物も含み、相関図内に内部IDは表示しません。
名前や関係の長い表示は省略し、全文・説明は画面下部の関係一覧やSVG内のツールチップで確認できます。
SVGをダウンロードしてブラウザーで開くことができ、ChatGPT共有ZIPにも `04_RELATIONSHIPS.svg` として同梱します。
相関図は作成時点のコピーです。関係を変更したら再度ダウンロードしてください。

## ブラウザーでの回帰テスト

PlaywrightとChromiumが利用できる環境で、既存データを使わない専用アプリに対して実行します。

```sh
# 別ターミナルで起動（メモリーDB、既存のdata・uploadsを使いません）
java -jar target/character-manager-0.0.1-SNAPSHOT.jar --server.port=18080 --spring.datasource.url=jdbc:h2:mem:browser-check --noctalith.upload-directory=/tmp/noctalith-browser-uploads
# Playwrightはリポジトリ外に用意し、必要ならモジュールへのパスを指定
BASE_URL=http://127.0.0.1:18080 PLAYWRIGHT_MODULE=/path/to/playwright node src/test/browser/profile-favorite.cjs
```

`CHROMIUM_PATH` でブラウザーのパスを指定できます（既定値 `/usr/bin/chromium`）。
お気に入り操作時の再読込の有無、次回検索での更新、通信失敗、性別・胸囲の入力と保存、相関図の表示とダウンロードを検証します。


## 主人公

一覧の「主人公を追加」から登録できます。通常キャラクターの上に専用の枠を設け、主人公を先頭に表示します。
入力項目は名前・基本設定・性別・身長のみです。胸囲・所属・タグなどのプロフィール入力は表示しません。主人公の登録後、編集画面で画像の追加・代表画像の指定・個別削除ができます（最大20枚、1枚5MBまで）。代表画像は一覧・詳細に表示し、画像と説明はバックアップ・共有ZIPにも含まれます。
関係は主人公の編集画面、または相手キャラクターの編集画面から登録できます。
主人公も修正履歴、削除、バックアップと追加復元、ChatGPT共有ZIPの対象です。
既存キャラクターの世界は保持します。起動時のスキーマ更新により、以前のH2の世界区分から主人公を登録できる型へ自動更新します。

## 相関図の選択と共有

相関図をアプリと同じ暗色・紫・ゴールドのデザインに変更しました。
主人公を中央に、オルタパレス・異世界・現代世界それぞれの枠に人物を配置します。
内部IDや、下部に重複していた全員の一覧は図から取り除きました。

「相関図に表示するキャラクター」で複数人を選び、「表示を更新」を押すと、選んだ人物に直接かかわる関係とその相手だけを表示します。
主人公は図の中央に残りますが、未登録の関係を自動で追加することはありません。
選択した人物から2段階以上離れた関係は表示しません。未選択、または「全員を表示」で全体図に戻ります。
同じ選択がSVGのダウンロードと「この相関図を含む共有ZIPを保存」にも反映されます。
共有ZIP内の設定・画像は従来どおり全キャラクターを対象とし、相関図だけを現在の選択に合わせます。

お気に入りの保存成功時はメッセージを出しません。失敗時には再試行できるようエラーを表示します。
胸囲の入力ラベルは「胸囲」とし、単位と女性の場合のみ保存するルールは従来どおりです。

ブラウザーテストには `src/test/browser/protagonist-map.cjs` も追加しました。専用DBで `profile-favorite.cjs` の後に実行すると、
主人公の入力欄・一覧の順番・文言・複数選択・暗色相関図・ダウンロード・モバイル表示を確認できます。
