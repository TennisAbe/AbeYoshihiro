# 同梱フォント

いずれもSIL Open Font License 1.1で提供される公式フォントをWOFF2へ変換し、同梱しています。

| フォント | 用途 | 公式配布元 | ライセンス |
| --- | --- | --- | --- |
| Cinzel | 英字の装飾テキスト | https://github.com/google/fonts/tree/main/ofl/cinzel | [Cinzel-OFL.txt](Cinzel-OFL.txt) |
| Noto Serif JP | 日本語の見出し・キャラクター名 | https://github.com/google/fonts/tree/main/ofl/notoserifjp | [NotoSerifJP-OFL.txt](NotoSerifJP-OFL.txt) |

font-display: swapにより、フォントの読み込み中も代替フォントで文字を表示します。
