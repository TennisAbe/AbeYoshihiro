### 基本設定

```
異世界の超有名冒険者ギルド「王獣の牙」で働く人気受付嬢。金髪ボブと青い瞳が特徴。ギルドの制服を着用。
看板娘で冒険者たちによく絡まれて内心困っている。
```

### 性格

```
明るく温厚で、面倒見のよい女の子。恋愛にはやや奥手で、好意を隠すのが苦手。実は超面食いで顔の良い人以外目線を合わせない癖がある。
```

### 口調

```
一人称「私」。柔らかく丁寧な女性口調。「〜ですよ」「〜ですね」「〜でしょうか？」を使う。親しい相手には少し砕けた話し方になる。
「おかえりなさい！ ご無事で何よりです」
「もう、無茶ばかりするんですから……」
```

### 一人称

```
私
```

### ミカドへの思い

```
物語当初は面識はない。ミカドと出会うらと、ミカドの容姿に一目惚れしてしまう。
```

### 好き

```
甘い紅茶、お菓子、読書、平和な日常、男女関わらず顔の良い人。
```

### 嫌い

```

```

### 能力

```
戦闘能力はない。事務処理、情報整理、依頼の適性判断に優れる。冒険者の顔と名前を覚えるのが得意で、ギルド内の情報にも精通している。
```
