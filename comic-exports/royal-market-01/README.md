# 王都市場と過保護な護衛たち

NOCTALITHの台本をもとにした全10ページの白黒漫画。右から左に読みます。各ページ5〜6コマで、会話する主要人物を1コマ4人程度に分けています。

- `NOCTALITH-royal-market-10pages.pdf`：全10ページの完成版。
- `page-01.png`〜`page-10.png`：ページ順の個別画像。
- `source-script.txt`：ユーザー提供の元台本。
- `storyboard.md`：制作時のページ構成。実画像と細部が異なる場合があります。
- `pages.json`：収録画像の順番・寸法・SHA-256。

## 登場人物と調整

ミカド（C000161）、パラム（C000147）、シノ（C000152）、ワイズ（C000156）、ソルベ（C000150）、シュカ（C000145）、町の迷惑客2人、店主・通行人。

シュカはユーザー確認により登録画像の黒い軍服を使用。ソルベの一人称は登録設定の「自分」、パラムの魔法は風属性へ統一。シノの和傘とシュカの鉄扇を混同していた初回生成箇所は、第4・6・8ページを画像生成ツールで修正した。第8ページ冒頭のコマ順も修正した。

台本の重複を整理し、残虐な制裁を負傷のない威圧・退散と衛兵への引き渡しに変更。元台本の流れである、王都へ出発→調査隊と合流→過保護な護衛の騒ぎ→異常原因の判明→買い物再開→シュカの報告のオチを収録。

保存済みの漫画見本と登場人物の原画像を実際に開いて参照した。
