# 炎軍団、火力ひかえめ。
白黒・右綴じ。登場人物はミカド、ホムラ、シュカの三人。舞台は炎軍団の石造りの訓練場。プリン、皿、標的、訓練用の滑車と鐘を繰り返し使う。

| 頁 | コマの流れと台詞 |
| --- | --- |
| 01 | 朝の訓練場。ホムラ「よし、ミカド！ 今日の特訓は派手にいくぞ！」→シュカが鉄扇を開く→ミカドが台座にプリンを置く。「今日は、これを守ってもらう。」 |
| 02 | ホムラがプリンの背後に敵を探す→誰もいない→ミカド「護衛対象はプリンだ」→シュカ「若様。対象は既に震えております」 |
| 03 | ミカド「鐘を鳴らして、プリンを無事に運べば合格」→ホムラ「勝った方が食えるんだな？」→ミカド「合格したら三等分」→ホムラ「じゃあアタシの分だけ先に避難させよう」 |
| 04 | 最初の課題は紙の標的だけを焦がす→ホムラが自信満々に剣を構える→標的が一瞬で消える→奥の壁に煤で丸い穴。「……的の中心は取っただろ？」 |
| 05 | シュカ「的ごと取ってどうするのじゃ」→扇で細い炎を曲げる→標的の中心だけ焦げる→台座のプリンも扇の風で真横に滑る。 |
| 06 | ミカドが片手で皿を受け止める→二人が息をのむ→ミカド「焦げてない。皿も割れてない」→ホムラ「採点してないで先に褒めてくれよ、その片手を！」 |
| 07 | 失点一ずつ。悔しがるホムラ→シュカが涼しげに髪を直す→髪から小さな焦げた紙片が落ちる→無言で鉄扇の下に隠す。 |
| 08 | 第二課題、狭い足場を渡る。ホムラが大股で進む→足場が揺れる→プリンが揺れる→三人とも同じ角度に傾く。 |
| 09 | シュカが歩幅を数えながら進む→ホムラが外から「おっそ！」→シュカが振り向く→ミカド「そこ、最後の一歩が戻ったぞ」 |
| 10 | 平均台の両端で言い合い→ミカドがプリンの安全確保のため腰を落とす→二人もつられて腰を落とす→三人、いつのまにか無言のスクワット。 |
| 11 | 休憩。ホムラ「こんな細かい火力調整、実戦で使うか？」→シュカ「守る相手が近いときほど要るのじゃ」→ホムラがミカドを見る→ミカド「食べてないぞ」 |
| 12 | シュカが空のティースプーンを渡す→ホムラが先を熱しすぎる→水に落として大きな音→ミカドが新しいスプーンを無言で差し出す。もう三本目。 |
| 13 | シュカ「手ではなく、目で先を追うのじゃ」→ホムラが剣先の火を小さく絞る→スプーンの水が小さく泡立つ→シュカ「その顔なら合格じゃ。舌はしまえ」 |
| 14 | ホムラが鉄扇を持つシュカの肩を観察→風が強すぎる瞬間を指摘→シュカが肘を引いて紙をそっと動かす→ホムラ「教え賃は一口な」 |
| 15 | ミカドが最終課題を示す。レールを走る籠でプリンを運び、反対側の鐘を鳴らす→ホムラが看板を指さす。「鐘、最初からあんな高かったか？」 |
| 16 | ミカド「高さは変えてない」→シュカが見上げる→ホムラ「じゃあアタシたちの自信が縮んだんだな」→シュカ「気づくのが早うて何よりじゃ」 |
| 17 | 一回目。ホムラが蝋の留め具を溶かして発車→シュカが炎の気流で籠を押す→勢いが合いすぎて終点を飛び越す→ミカドが皿を受け止める。 |
| 18 | ホムラ「ナイスキャッチ！」→ミカド「三回目はないぞ」→シュカ「まだ二回あったような言い方じゃ」→壁際にミカド用の受け止め位置の印が増える。 |
| 19 | 引きで位置を確認→ホムラ「アタシが離す。シュカ、お前が待つ」→シュカ「妾の合図まで、離すでないぞ」→二人同時に「どっちが先だ」 |
| 20 | シュカが床に合図の印を置く→ホムラが熱する位置を印す→ミカドが皿から三歩下がる→ホムラ「受け止め係が逃げた！」 |
| 21 | 再開。小さな火で蝋をゆっくり溶かす→シュカが籠の揺れを見て待つ→一拍置いて扇を振る→籠がレールを滑る。 |
| 22 | 途中で支柱がきしみ籠が傾く→ホムラが思わず大きい火を出しかける→シュカ「ホムラ様、目で追うのじゃ」→火が剣の先の一点に戻る。 |
| 23 | ホムラが予備の蝋留めだけを切る→シュカが横から炎の気流を送り籠を持ち直す→二人の目が合う→同時にうなずく。 |
| 24 | 籠が静かにゴールに着く→プリンがわずかに揺れる→全員が息を止める→揺れが止まり、ホムラが拳を握る。 |
| 25 | しかし鐘が鳴らない→紐の端が短すぎる→ホムラが肩車を提案→シュカが扇の要から細い風を当てると、舌だけが動く。 |
| 26 | 小さく「ちん」→三人とも耳を澄ます→ミカド「……合格」→ホムラが勝ち鬨を上げようとして、無言で拳だけ天に突き上げる。 |
| 27 | ミカド「二人だからできたな」→ホムラは豪快に笑う→シュカは返事に詰まり扇で顔を隠す→ホムラ「おい、そっちの火力は絞れないのか？」 |
| 28 | 台座に戻し三つのスプーン→ホムラが大きい切り分けを真剣な目で狙う→シュカの扇が進路を塞ぐ→ミカドが均等に分ける。 |
| 29 | 三人で一口→二人が驚くほど静かになる→ミカド「次は何を守る？」→ホムラ・シュカ「おかわり」 |
| 30 | 翌朝、炎軍団の訓練場→ミカドが覆いを取る→台座には山盛りのプリン→ホムラとシュカが鉄扇と剣を構え、息ぴったりに「火力ひかえめ！」 |
