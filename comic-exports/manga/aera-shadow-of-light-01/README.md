# 光を追う影 — NOCTALITH

ユーザーの修正版台本を原案とする全50ページの白黒漫画です。右から左、上から下へ読みます。冒頭の暗殺依頼から、ギルド登録・輝龍と大悪魔の討伐、アエラの闇軍団加入・訓練、顔写真を見つめる結末までを収録しました。

## 漫画を読む

- [前編：1〜25ページ（PDF）](NOCTALITH-aera-shadow-of-light-part-1-pages-01-25.pdf) — 約76.2MB。
- [後編：26〜50ページ（PDF）](NOCTALITH-aera-shadow-of-light-part-2-pages-26-50.pdf) — 約77.3MB。

GitHubのPDF画面でプレビューできない場合は、右上の **Download raw file（↓）** からダウンロードしてください。前後編は独立したPDFで、ZIP分割ファイルのような結合操作は不要です。

`page-01.png`〜`page-50.png` は番号順の個別原稿です。全ページ1024×1536px。PDFはこの原稿を画素変更せずに埋め込み、前後編各25ページに分けています。

## 台本・設定と演出

- アエラの技はユーザー指定により台本準拠。「影喰らい」「影刃」、分身は本人を含む3体です。
- 路地から洞窟への再会、移動所要時間、共闘の扱い、王都での引き渡し、次の約束の日付を整理しました。
- 重複する会話と説明を絵で伝える構成へ圧縮。強い怒り・驚き・照れ・得意顔・疲れを場面に合わせて描き分けています。
- 非性的な通常のキスを残し、性的な奉仕や過去の行為の示唆は省略。医務室の接触は、眠ったケトを支えて休ませる場面へ調整しました。
- 戦闘の勝敗と見せ場を保ち、損壊の接写を避けて光・影・煙で表現しています。
- 人物の原画像と登録プロフィールを照合し、今回受領した42人版ZIPのうち本作に登場する13人を参照しました。シノの和傘とホムラの本人右眼の眼帯を固有装備として扱っています。

## 収録資料

| ファイル | 内容 |
| --- | --- |
| `source-manifest.json` | 再添付された微修正版原案のファイル名・容量・SHA-256 |
| `adapted-script.md` | 漫画用に接続・圧縮を整理した台詞 |
| `storyboard.md` / `pages-plan.json` | 50ページの作画用構成・台詞・主感情。実原稿と小さな演出差がある場合はPNGを完成原稿とする |
| `adaptation-notes.md` | 台本の接続・圧縮・表現調整の記録 |
| `pages.json` | 各原稿とPDFのページ順・寸法・容量・SHA-256 |
| `qa-report.json` | 全ページの確認範囲・修正内容・機械検査結果 |
| `references/` | 今回使用した13人の原画像と個別設定。本文内の元相対リンクは元ZIPの構造に対応 |
| `reference-manifest.json` | 原画像の参照IDとSHA-256 |
| `build_pdf.py` | 原稿を変更せずPDFへまとめる再構築スクリプト |

50枚すべてを実画像で確認し、見つかった帽子・受付嬢の外見・眼帯の左右・背景・物語の連続性等を画像生成で修正しました。PDF全50ページの埋め込み画素データが原稿PNGと一致すること、各PDFが100MB未満であることも検査済みです。ユーザーによる作品レビューは未受領です。

## 再構築

PythonとPillow・ReportLab・pypdfを用意し、このフォルダーで `python3 build_pdf.py` を実行してください。元PNGの画素を変更せず前後編PDFと `pages.json` を再作成します。
