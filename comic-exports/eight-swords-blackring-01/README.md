# NOCTALITH 八星剣戦記『黒環の砦』

白黒・全30ページのオリジナル戦闘読み切り。八星剣八人とミカド、今回限りの敵・虚鎧ヴァルクが登場。最大6コマ、同時に映る人物は原則4人以内。

- `NOCTALITH-blackring-part1-pages01-15.pdf`：前編1〜15ページ、約61MB。
- `NOCTALITH-blackring-part2-pages16-30.pdf`：後編16〜30ページ、約59MB。
- `page-01.png`〜`page-30.png`：ページ順の完成原稿。

- `pages.json`：本編ページ順と原稿ハッシュ。
- `qa-resolved.json`：制作中の修正記録。

## 方針と検品

八人の属性・技名・口調は保存済みの設定本文、外見は各人の原画像を参照。敵と事件の新規創作はユーザー了承済みで、既存の確定設定として登録していない。全員の見せ場を入れ、反射装甲の観察→連携して軸を破壊→暴走核の切り離し→帰還で完結する。

ヤミに混ざった眼帯（10ページ）と金属鎧（15・20ページ）を修正。18ページに混入した制作説明風の文章を削除。21ページの残存鏡板数、24ページの破壊済み鏡板の再出現、30ページの空に残った黒環を修正した。修正後の画像を再確認。

本編全30原稿を目視し、画像の正常性、PDFページ順・ページ数、画像ハッシュを確認。細部の鏡板の角度や形、技名のルビ等は生成による揺れがあり得る。ユーザーレビューは未受領。以前の作品は変更していない。
