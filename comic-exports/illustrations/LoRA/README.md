# NOCTALITH LoRA

各キャラクターフォルダに学習用ZIPと、学習済みLoRAで試すプロンプトのメモがあります。

①は顔と体つきの指定です。衣装を替える場合は、①の後ろに着せたい服を追加してください。②は学習画像の衣装まで合わせる指定です。体つきを確認するときは前からの全身構図が向いています。

プロンプト先頭のトリガーワードは学習キャプションと照合済みです。後続の語句は参照画像をもとにした補助指定です。学習後の生成結果は未検証で、学習画像の衣装が①にも出る場合があります。
