# 海とプール ― ミカド目線の一枚絵41人

海辺やプールで二人が過ごす夏の一場面を、ミカドの視点で一人一枚ずつ描いた。前のデート集より表情や手元に寄り、遊びの内容を示す波打ち際、プールの縁、小物などを画面に入れた。ミカドの手や足は、視点や動作の手掛かりになる場面に描いた。ミコトは兄妹のお出かけ。

髪型、瞳、装飾は登録画像を参照し、水着は各場面に合わせて設定した。ホムラは既存の海編に合わせた真紅の水着。線と色面、ミカド目線の演出は[追加カラー参考集](../../reference-images/100kano-kyusai-all/)を参照。寸法、参照ID、SHA-256は [manifest.json](manifest.json) に記録。

## 原稿確認

全41枚で顔や状況に加え、見える腕を肩から手まで追って確認し、前景がミカドの手足として読める位置かを点検した。重なりや反射を見分けにくい部分は拡大し、崩れが見つかった絵は修正後に再確認した。

ワイズはベンチ側に描かれていた余分な腕を除き、本を押さえる腕と頬に添える腕がそれぞれ肩からつながることを確認した。サタニアはタオル左端の体につながっていない足を除き、本人は手、ミカドはサンダルを履いた足でタオルの端を押さえる構図にした。
