# 七天魔王とのデート ― ミカド目線

七天魔王7人を各1枚。ミカドは画面外の視点人物。前の一枚絵シリーズと同じく、キャラクターごとの登録衣装を基準に、食事以外の場面を描いた。

| キャラクター | 場面 | 原稿 |
| --- | --- | --- |
| ルシフェリア | 夜の天文台で、気取った顔のまま望遠鏡の場所を譲る | [PNG](luciferia.png) |
| レヴィアナ | 水中回廊で、魚を見ているミカドが振り向くのを待つ | [PNG](leviana.png) |
| サタニア | 夕暮れの高台で、ミカドの前でふと肩の力を抜く | [PNG](satania.png) |
| フィナ | からくり展示で、天体模型を見せながら穏やかにくつろぐ | [PNG](fina.png) |
| モニカ | 灯籠の下の骨董市で、どちらを選ぶかミカドに委ねる | [PNG](monica.png) |
| ベル | 春祭りの輪投げで取ったぬいぐるみを差し出す | [PNG](bel.png) |
| アスティリア | 藤棚の散歩道で、照れを隠しながら散歩の続きを誘う | [PNG](astilia.png) |

キャラクターは登録画像を参照。カラー作画には参考集01・38を使用。場面と小物は今回の一枚絵の演出として創作した。描画寸法・参照ID・SHA-256は `manifest.json` に収録。
