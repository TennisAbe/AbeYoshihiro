# キャラ一枚絵・漫画の追加作画参考

2026年11月15日、ユーザー提供の `100kano-kyusai-all.zip.001` と `.002` を順に結合して展開しました。PNG全38枚を元のファイル名・元のバイト列のまま保存しています。

## 用途と使い方

ユーザー指定の主用途は **キャラ一枚絵を生成する際の参考画像** です。漫画の画風にも活用します。生成の前に、この一覧から場面に合う原画像を実際に開き、NOCTALITHのキャラ原画像・設定と併せて参照してください。

- 一枚絵：画角、人物と背景の比率、目線、手の仕草、表情、配色、光と影、髪のハイライトを参照する。キャラごとの登録済み髪型・色・衣装・眼帯・装備等は維持する。
- 漫画：顔の白場、小さい鼻口、上まぶたの強弱、髪の面とハイライト、表情とデフォルメの差、見せ場の構図を取り入れる。カラーの光や色面は、白黒のトーン・黒ベタ・余白へ整理する。既存の白黒・コマ数等の条件は制作引き継ぎに従う。
- 見本の人物・名前・衣装・関係性は、NOCTALITHの新設定として登録しない。既存作品の作り直しや、新規画像の生成をこの資料追加だけで開始しない。

## 確認状況

分割ZIPの結合後にZIP全体のCRC検査、PNG38枚のデコード検証、寸法取得、SHA-256記録を実施。ハッシュは38種類で、同一バイト列の重複はありません。個別の寸法・容量・ハッシュは [manifest.json](manifest.json) を参照してください。元の分割ZIPは重複保管せず、展開済みの全画像をコミットしています。

目視では `kyusai01`（カフェで手を前へ差し出す構図・暖色光）、`kyusai19`（通常等身とデフォルメの集合構図）、`kyusai38`（暗い室内の斜め顔・光と色の分離）を代表として確認しました。全38枚の細部を目視照合済みという意味ではありません。実制作では必要な画像を原寸で確認してください。

このZIPは新たなカラー参考画像集です。前回チャットで提示された12枚の漫画見本との一致は確認していません。`style-additions-20261115/` の原画像未保存状態を、このZIPの受領だけで保存済みに変更しません。
