## 今後の作画に取り入れる観察

以下は見本からの観察・制作上の解釈です。ユーザーが『光を追う影』を不合格と評価した、または描き直しを命じたという記録ではありません。

### 顔と目

輪郭と鼻・口の線を少なくし、顔は白場を大きく保ちます。上まぶた・上まつ毛は黒を強め、下側は少ない線で整えます。目は場面によって大きく開く・半目にする・簡略化する差を付け、通常の目の描き込みを全コマへ一律に使いません。大きい白い反射や細かな輝きは感情の寄りに使います。

照れは、頬や鼻筋の短い斜線、視線をそらす、口元を指で隠す、眉を下げる、涙目にする等を組み合わせます。全員を同じ星目・赤面・笑顔に均しません。B04のような眼鏡越しの目では、フレーム・髪・瞳が重なっても表情が読める余白を保ちます。

### 髪と服

髪は束の外形、黒ベタや均一なトーン、つながった白いハイライトで形を出します。細い毛筋や写実的な光沢の量を増やすことを、完成度の代わりにしません。長髪・巻き髪・ボブでシルエットを変えます。

服は全身のシルエット、重なり、主要なしわ、トーンの面積で読ませます。引きのコマへ顔アップと同じ密度の線を入れません。見本にある私服・水着・眼鏡等を、NOCTALITHキャラクターの確定衣装・装備として取り込みません。

### コマ割りと身振り

全身像を見せる縦長コマ、静かな顔アップ、短い会話コマ、横長の動作コマを使い分けます。毎ページを同じ高さの横長4段だけに固定しません。視線の向き、手元、体の傾き、相手との距離を使い、説明台詞だけに頼らず関係や反応を伝えます。

日常の柔らかい場面と、デフォルメ・集中線・大きな口・太い叫び文字のギャグを切り替えます。台本が強い感情を要求する場面を、軽い絵柄という理由だけで穏やかな会話に変更しません。

### 文字と背景

縦書きの漫画用アンチック体・明朝風の台詞を基本とし、ツッコミや叫びは太いゴシック風、効果音は手描き風で強弱を付けます。見本から正確なフォント名が特定できたとは扱いません。読み順と吹き出しの尾を、話者の口・顔・身振りと合わせて確認します。

背景は場所を示す建物・家具・遠近・水面を必要なコマに置き、反応の顔アップでは減らします。背景の密度や装飾が顔・手・台詞の読みやすさを上回らないようにします。

## キャラクター設定との分離

参考にするのは線・トーン・構図・表情・コマのリズムです。見本の人物をNOCTALITHの人物と同一視しません。ホムラの本人右眼の黒い眼帯、非常に長い高位置のポニーテール、ミカドの長い銀髪と軍服、シノの和傘、各人の一人称と口調などは、キャラクター資料の方で確認します。

## 原画像を受け取ったら

1. 元PNG/JPEGをZIPまたは取得可能な添付として受け取ります。
2. 表示内容とA01〜B04の対応を確認し、原画像を加工せず別名で保存します。似た見本を無理に既存IDへ当てはめません。
3. `manifest.json` に実ファイルの相対パス、元ファイル名、寸法、SHA-256を記録します。A07/A08等のバイト列の一致も照合します。
4. このREADMEと引き継ぎの未保存表記を、実際に保存できた分だけ更新します。全件保存・全件照合を先に宣言しません。
5. 画像本体も含む変更を `comic/noctalith-pdf-export` へプッシュし、リモートでファイルの存在を確認します。
