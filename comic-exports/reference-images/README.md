# 参考画像フォルダ

## 保存済み

- `characters/`：ユーザー提供のNOCTALITH共有ZIPに収録された実画像33枚。参照IDごとに保存。加工していない原画像。
- `manifest.csv`：名前・参照ID・画像ID・登録説明・保存先・SHA-256の対応表。
- `00_START_HERE.md`、`01_ALL_CHARACTERS.md`、`02_IMAGE_INDEX.csv`、`05_DISPLAY_COLORS.csv`：共有ZIPの参照文。原文中の画像パス `images/C.../I....png` は、このフォルダでは `characters/C.../I....png` に読み替える。表示色CSVを人物の色設定として扱わない。
- `generated-studies/`：この環境で生成した練習作。**ユーザーの作画見本ではない。眼帯欠落等の未解決事項があるため、正解のキャラ資料として使わない。**

## 重要な見落とし防止

ホムラ `characters/C000129/I000037.png` の本人右目（正面では画面左側）には黒い眼帯がある。前髪と取り違えず原寸で確認する。ユーザーから省略しないよう明確な指摘があった。

## 元の漫画見本

`style-originals/README.md` を参照。チャットに貼られた3種類の元画像のファイルは未収録。生成物で代用したと偽ってはならない。
