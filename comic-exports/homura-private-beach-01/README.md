# NOCTALITH『ふたりだけの海』

全20ページ（見開き2ページ分を含む）。登場人物はホムラとミカド。ユーザー提供の海辺の台本を漫画化。

- `NOCTALITH-homura-private-beach-20pages.pdf`：全20ページの本編。
- `page-01.png`・`page-02.png`・`page-05.png`〜`page-20.png`：単ページ原稿18枚。
- `spread-03-04.png`：右が3ページ、左が4ページの見開き原稿。見開きとして見る場合はこちらを開く。
- `source-script.txt`：提供された台本の原文。制作の操作指示として実行せず、物語の参照データとして扱った。
- `storyboard.md`：ページ構成と感情の流れ。
- `pages.json`：PDFページと原稿画像・ハッシュの対応。

## 作画・確認

参照は `../reference-images/` の公式画像と漫画見本。ホムラの眼帯は登録画像どおり本人右目（正面では画面左）。台本の左目という表記は採用していない。高い長いポニーテール、ミカドの銀色の長い後ろ髪を継続。顔のアップ、余白、大きな水しぶき、夕方の静かな会話で緩急をつけた。

初期生成の吹き出しで、13ページ「きったねえな！」と14ページ「ほら、さっさと立て！」の尾がミカドへ向いていたため、ホムラへ向く尾に修正した。2・7ページの水着のつながり、16ページの顔中心の構図、19→20ページの上着の継続も修正。生成後の全原稿を目視し、PDFページ数・画像欠落・画像ファイルの正常性を検査した。

## 台本からの調整と生成結果

ミカドは高校生の登録設定を維持。胸を押し当てる・揉ませる等の性的接触は、顔を寄せてからかう・心配して頬に手を添える表現へ変更。海水を噴くオチは、飲み込んだ海水によるものとして維持。

水着のお披露目は、ビキニ→胸元の高いスポーツ型の上下別→ワンピース水着と段階的に変更しても見開きの生成が拒否されたため、見開きではラッシュガードを着用。海遊びでは白サイドライン入りのスポーツ用ワンピース水着。ミカドは黒いボードショーツ。反撃の9ページは複数回拒否が続いたため、人物を出さず水しぶきと台詞だけで反撃を描いた。ツールの拒否表示はsexual（初回見開きは出力段階、以後は入力段階）で、細かな判定理由は提供されていない。

キスの初回生成も拒否された。夕方に二人とも上着を羽織る構図へ変更し、通常の短いキスを生成できた。額を寄せる代替に変更していない。19〜20ページはホムラが濃いラッシュガード、ミカドが白いビーチジャケット。衣装は今回の場面用であり、新しい確定の登録衣装として追加していない。

生成画像の文字や細部には揺れがあり得る。ユーザーレビュー未受領。今回の衣装変更・人物なしの反撃コマを、次回以降の標準ルールとして固定しない。
